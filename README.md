# AllMail

AllMail is a full-stack centralized inbox dashboard built with Spring Boot, React, and PostgreSQL.

The goal of the app is to let users manage messages from multiple email accounts in one unified inbox. For the first version, the app uses local database records and sample email data. The backend is designed so OAuth-based Gmail and Microsoft account connections can be added later.

## Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- React
- Vite
- TypeScript

## Planned Features

- View messages from all connected accounts in one inbox
- Filter messages by account
- Open message details
- Mark messages as read or unread
- Star important messages
- Archive or delete messages
- Add placeholder connected accounts
- Prepare the structure for future OAuth integration
